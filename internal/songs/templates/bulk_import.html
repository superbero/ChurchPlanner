BULK WORKFLOW

Upload songs or a song list

Select multiple PDF, ChordPro (.cho, .pro, .chordpro), OpenSong/OpenLyrics XML, or plain-text files. Each file becomes one song and its title, author, key, and tempo are read when available.

Or upload a CSV with one song per row. Its source_content column can contain ChordPro or plain lyrics; quote it as a CSV field, especially when it contains commas or line breaks. Upload CSVs by themselves, not mixed with song files.

Download example CSV

Import behavior

For CSV, title and one content column (source_content, chordpro, or lyrics) are required. author, key, and tempo are optional.

PDF text is extracted; XML metadata and lyrics are converted to ChordPro. Plain text and ChordPro content are supported directly. Existing songs with the same title are suggested for review; the importer never silently discards them.

Choose to create a new song, skip the row, or add the imported chart as an arrangement to an existing same-title song. All decisions save together; if any save fails, the batch is rolled back.
